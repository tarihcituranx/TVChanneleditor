## 1. Project Overview
**Name:** TVChannelEditor (Samsung SCM Editor)
**Description:** A web-based (Flask) tool designed to edit, view, and modify Samsung Smart TV channel list files (`.scm` format) directly in the browser via a drag-and-drop interface.
**Target Audience:** Users who want to sort their satellite channels, remove encrypted/radio channels, or update frequencies for Türksat (Turkey).

## 2. Architecture & Tech Stack
*   **Backend:** Python 3.12+ with Flask (`app.py`).
*   **Frontend:** Vanilla JavaScript (`static/js/app.js`), standard HTML5 (`templates/*.html`), and Vanilla CSS (`static/css/style.css`). No heavy frontend frameworks are used.
*   **Translation (i18n):** Multi-language is handled through routing. The backend checks `request.accept_languages` or the `lang` cookie. English templates are suffixed with `_en.html` (e.g., `index_en.html`).
*   **Deployment:** Configured to run on Render.com using `gunicorn`.

## 3. Core SCM Logic (`scm_core.py`)
Samsung SCM files are essentially unencrypted ZIP archives.
*   **`map-SateD`:** Contains the channel ordering and details. Each record is 168 bytes (for E/F series). Checksum is calculated at the 167th byte: `sum(bytes[:167]) % 256`.
*   **`TransponderDataBase.dat`:** Contains the frequencies. Transponder index in `map-SateD` matches records here to assign frequencies to channels.

## 4. Automatic Frequency Validation
*   **The Problem:** Satellite frequencies change over time, rendering old channels blank/dead.
*   **The Solution:** The app automatically flags outdated frequencies.
*   **How it works:** 
    - The JSON database `static/data/frekanslar.json` is generated by scraping `frekanslistesi.com.tr`.
    - In `app.js`, `renderChannels()` cross-references each channel's frequency against this JSON. If the frequency is outdated or missing, a visual warning (⚠️ Eski Frekans) is rendered.

## 5. Security & Guidelines
*   **API Keys:** NEVER commit API keys (e.g., DeepL) to the repository. Always use environment variables (`os.environ.get()`).
*   **Dependencies:** Keep `requirements.txt` minimal. Currently relies only on `Flask`.
*   **Credits:** The logic is heavily inspired by Open-Source contributions from **İltekin**, **PredatH0r (ChanSort)**, and the **SamyGO** community. Always preserve their credits in the footer and `README.md`.
*   **Modifications:** Do not break the 168-byte structure in `scm_core.py`. A single wrong byte will cause the Samsung TV to reject the USB file.
