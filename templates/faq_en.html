❓ Frequently Asked Questions

What Is an SCM File?
SCM (Samsung Channel Map) is a special archive file that stores channel listings, favorite lists, and frequency data for Samsung TVs. It contains map-SateD (channel list) and TransponderDataBase.dat (frequency database). Older models use the SCM format, while newer Tizen models use the ZIP format.
How do I transfer the channel list from the TV to a USB drive?
For Samsung: Menu → Broadcast → Channel Settings → Transfer Channel List → Transfer to USB.
For LG: Settings → Channel → Copy to USB.
For Sony: Settings → Channel Settings → Channel List Transfer → Transfer to USB.
For Hisense: Menu → Channel → Export Channel List.
How do I load the edited list onto the TV?
Copy the downloaded file to a USB drive (keep the original file name! ). Use the “Import from USB” or “Import” option in the TV menu. On Samsung TVs, the TV usually only accepts files with the exact same name; therefore, save the new file with the same name as the old one.
Which TV brands are supported?
Currently, Samsung (.scm and .zip), LG (.tll), Sony BRAVIA (sdb.xml), and Hisense (servicelist.db) are fully supported. Panasonic is in the beta phase; Philips, Toshiba, and Grundig will be added soon.
How does Magic Wand match channels?
Magic Wand matches channels based on the channel name (case-insensitive). If your channel list in the template includes “TRT1 HD,” it will find the “trt1 hd” channel in the uploaded file and move it to the top. It does not alter the frequency or PID data.
Is my data secure? Are my files stored on the server?
Uploaded channel list files are stored temporarily on our server only for the duration of the processing and are deleted as soon as the process is complete. No channel names, frequencies, or personal data are logged, stored, or shared with third parties. All processing is done on the server, and only the output file is sent to you.
What does the frequency warning (⚠️ Old Frequency) mean?
The system compares the frequency at which the channel was recorded with the current Türksat frequency database on the official Türksat website. If the channel was scanned at an old or different frequency, a yellow warning is displayed. This is for informational purposes only; the channel will continue to work, but it is recommended that you move the channel to its current frequency by performing a new network scan on your TV.
Why can’t I see the new unencrypted channels in the list?
This site only manages the TV’s current channel list; it cannot add new channels. To view a new channel, you must first perform a Network Scan on the TV, then download the new SCM/ZIP file.
I can’t upload a file larger than 2 MB—what should I do?
A 2 MB upload limit is in place for security reasons. However, typical channel list files are well below this limit; an SCM file containing hundreds of channels rarely exceeds 300–400 KB. If you’re uploading a very large file, you’ve likely selected the wrong file.
What is a TLL file on an LG TV, and how do I obtain one?
TLL (TLL Channel List) is the GlobalClone backup format for LG TVs. Insert a USB flash drive into the TV and export the file via the Settings → General → About → Channel Backup Configuration (CLONE) menu. On some models, the path is different: You can check the file created after selecting Menu → Support → Update → Update via USB . The file is usually named xx########.tll .
Where is the sdb.xml file located on a Sony BRAVIA?
For Sony BRAVIA, insert a USB flash drive and follow these steps: Settings → Channel Settings → Channel List Transfer → Copy to USB. After the process, a file named sdb.xml . On some Android TV models, use the path Settings → Device Preferences → Channels → Back Up Channel List.
How do you retrieve the servicelist.db or channel.db file on a Hisense TV?
For Hisense, insert a USB flash drive and go to Menu → Channel → Export Channel List. On the USB drive, servicelist.db or channel.db . The file name may vary depending on the model and firmware version; both formats can be opened with this editor.
Should I use a ZIP file or an SCM file on a Samsung Tizen TV?
Older Samsung models (E, F, H Series, 2012–2014): .scm use files with the .SCM extension.
Newer Samsung Tizen models (J, K, M, Q, R, T Series, 2015 and later): .zip use files with the .SCM extension that contain an SQLite database.
This editor automatically detects both formats; it selects the correct format by examining the ZIP contents, not by the file extension.
How do I know which file to load?
Check the file extension based on your TV brand:
• Samsung (older models) : .scm
• Samsung (Tizen/new): .zip
• LG: .tll
• Sony BRAVIA: sdb.xml
• Hisense: servicelist.db or channel.db After uploading
the file, the editor automatically displays which brand it has detected.
