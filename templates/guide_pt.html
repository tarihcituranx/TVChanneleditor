Guia do Utilizador

1 Transferir a lista de canais para uma unidade USB
Utilizando o comando da televisão, siga estes passos: Menu → Transmissão → Definições de canais → Transferir lista de canais. Introduza o seu PIN (normalmente 0000 ) e selecione a opção «Transferir para USB ».

Modelos mais antigos (E/F/H): .scm É criado um ficheiro.
Modelos mais recentes (J/K/M/Q/R/T - Tizen): .zip é criado um ficheiro.
2 Carregar o ficheiro para o site
Ligue a pen USB ao seu computador. Arraste o ficheiro para a área de carregamento na página inicial .scm ou .zip arraste e solte o ficheiro na área de carregamento na página inicial, ou clique no botão «Selecionar ficheiro».
3. Organizar canais
Reordene os canais utilizando a função arrastar e soltar. 🪄 Aplique modelos pré-definidos com os Smart Templates ou 🛠️ crie os seus próprios com o Template Creator. Pode alterar os ícones de 🔒 bloqueio e de favorito em cada linha de canais.
4. Guardar e carregar para a TV
Clique no botão «Guardar e descarregar» . Copie o ficheiro descarregado para uma pen USB (utilize o mesmo nome que o ficheiro original!). Carregue-o através do menu da TV utilizando a opção «Carregar a partir de USB ».
💡 Dica: a TV só reconhece ficheiros SCM com exatamente o mesmo nome. Ao copiar o novo ficheiro para a pen USB, substitua o antigo ou faça uma cópia de segurança do antigo .bak com a respetiva extensão.
⚠️ Aviso: O processo de edição de canais não altera as frequências nem os dados PID encriptados dos canais existentes; apenas atualiza a ordem e os indicadores.
1 Transferir a lista de canais para o USB
Na sua TV LG, aceda a Definições → Canais → Gestão de canais → Copiar canais para USB. Na unidade USB GlobalClone00001.TLL ou LG_DTV_*.tll será criado um ficheiro como este.
2. Carregue o ficheiro .TLL
Carregue um ficheiro com a extensão .tll . O sistema reconhecerá automaticamente o formato XML do GlobalClone.
3. Editar e descarregar
Ordene os canais utilizando a função «arrastar e largar». Clique no botão «Guardar e descarregar» para descarregar o ficheiro TLL atualizado e transfira-o para uma pen USB. Conclua o processo selecionando «Carregar canais a partir da pen USB» no menu da TV.
💡 Nos dispositivos LG webOS 5, podem, por vezes, aplicar-se restrições à importação da lista de canais. Se vir um ecrã preto, tente reiniciar a televisão.
1. Obter o ficheiro sdb.xml
Numa Sony BRAVIA, siga estes passos: Definições → Configuração de canais → Importação da lista de canais → Importar para USB. Na unidade USB sdb.xml ou em subpastas *.xml serão criados ficheiros.
2. Carregar o ficheiro sdb.xml
Vá para o ecrã inicial sdb.xml . O sistema reconhece automaticamente o ficheiro no formato da Sony e apresenta a lista de canais.
3. Editar e carregar para a TV
Edite os canais e, em seguida, clique em «Guardar e descarregar» para sdb.xml transferir o ficheiro. Copie-o para uma pen USB e carregue-o na TV utilizando a opção «Importar do USB».
1. Obter o ficheiro servicelist.db
Na sua televisão Hisense, aceda a Menu → Canal → Exportar Lista de Canais para transferir o ficheiro da base de dados para uma pen USB. O nome do ficheiro é normalmente servicelist.db (2017+) ou channel.db (2015–2016).
2. Instalar a base de dados
Arraste o servicelist.db . O sistema lê a base de dados SQLite e apresenta todos os canais.
3. Editar e carregar
Depois de efetuar as alterações pretendidas, clique no botão «Guardar e descarregar» para descarregar o ficheiro da base de dados atualizado. Copie-o para uma pen USB e utilize o menu de importação da televisão para o importar.
⚠️ As alterações ao nome dos canais são limitadas nos modelos Hisense; em alguns modelos, apenas é possível aplicar alterações à ordenação e ao bloqueio.
