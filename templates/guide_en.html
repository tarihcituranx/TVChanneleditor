📖 User Guide

1 Transfer the Channel List to a USB Drive
Using the TV remote, follow these steps: Menu → Broadcast → Channel Settings → Transfer Channel List. Enter your PIN (usually 0000 ) and select the "Transfer to USB" option.

Older models (E/F/H): .scm A file is created.
New model (J/K/M/Q/R/T - Tizen): .zip a file is created.
2 Upload the File to the Website
Plug the USB drive into your computer. Drag the file to the upload area on the homepage .scm or .zip drag and drop the file into the upload area on the homepage, or click the "Select File" button.
3. Organize Channels
Reorder channels using drag-and-drop. 🪄 Apply ready-made templates with Smart Sorting or 🛠️ create your own with the Template Creator. You can change the 🔒 lock and ⭐ favorite flags on each channel row.
4 Save and Upload to TV
Click the Save and Download button. Copy the downloaded file to a USB drive (use the same name as the original file!). Load it via the TV menu using “Load from USB .”
💡 Tip: The TV only recognizes SCM files with the exact same name. When copying the new file to the USB drive, either overwrite the old one or back up the old one .bak with its extension.
⚠️ Warning: The channel editing process does not change the frequencies or encrypted PID data of existing channels; it only updates the order and flags.
1 Transfer the Channel List to USB
On your LG TV, go to Settings → Channels → Channel Management → Copy Channels to USB. On the USB drive GlobalClone00001.TLL or LG_DTV_*.tll a file like this will be created.
2. Load the .TLL File
Upload a file with the .tll . The system will automatically recognize the GlobalClone XML format.
3. Edit and Download
Sort the channels using drag-and-drop. Click the "Save and Download" button to download the updated TLL file and transfer it to a USB drive. Complete the process by selecting "Load Channels from USB" from the TV menu.
💡 On LG webOS 5 devices, channel list import restrictions may sometimes apply. If you see a black screen, try restarting the TV.
1. Get the sdb.xml File
On a Sony BRAVIA, follow these steps: Settings → Channel Setup → Channel List Import → Import to USB. On the USB drive sdb.xml or in subfolders *.xml files will be created.
2. Load the sdb.xml File
Go to the home screen sdb.xml . The system automatically recognizes the file in the Sony format and lists the channels.
3 Edit and Upload to TV
Edit the channels, then click Save and Download to sdb.xml download the file. Copy it to a USB drive and load it onto the TV using "Import from USB."
1. Get the servicelist.db File
On your Hisense TV, go to Menu → Channel → Export Channel List to transfer the database file to a USB drive. The file name is usually servicelist.db (2017+) or channel.db (2015–2016).
2. Install the Database
Drag the servicelist.db . The system reads the SQLite database and lists all channels.
3 Edit and Upload
After making the desired changes, click the "Save and Download" button to download the updated database file. Copy it to a USB drive and use the TV’s import menu to import it.
⚠️ Channel name changes are limited on Hisense models; on some models, only sorting and lock changes can be applied.
