📖 User Guide

1. Transferring the File to a USB Drive
Press the Menu button on your TV remote. Follow the steps: Broadcast > Channel Settings > Transfer Channel List. On the screen that appears, enter your PIN code (usually 0000) and select "Transfer to USB."
2. Loading the SCM File
Plug the USB drive into your computer. Drag and drop or select the file with the .scm file from the USB drive into the field on this website’s homepage.
3. Organizing Channels
Once the file is uploaded, you can manually reorder the channels by dragging and dropping them with your mouse. If you prefer, you can use the 🪄 Magic Wand button to apply one of the pre-made templates (General, Sports, News, etc.) with a single click.
4. Creating a Template
🛠️ Use the Template Creator button to create your own custom layout template and save it to your browser. This way, you can apply your own template with a single click the next time you upload a file.
5. Save and Upload to TV
Once you’ve finished editing, click the Save and Download button to download the new .scm file to your computer. Transfer this file back to a USB drive, then complete the installation by selecting the “Load from USB” option in your TV’s menu.
