Willkommen beim TV-Sender-Editor! 👋

Schluss mit stundenlangem Herumprobieren mit der Fernbedienung Ihres Fernsehers! Exportieren Sie einfach Ihre Senderliste auf einen USB-Stick und laden Sie sie hier hoch. Organisieren Sie Ihre Sender ganz einfach per Drag-and-Drop oder nutzen Sie die „Smart Templates“ 🪄, um sie in Sekundenschnelle zu sortieren.

Deine Datei wird auf unserem Server nur vorübergehend verarbeitet, um die Senderliste auszulesen. Sie wird niemals dauerhaft gespeichert.

Legen Sie Ihre Senderliste hier ab

.scm · .zip · sdb.xml · servicelist.db

Sicherer Vorgang: Ihre Dateien werden nur während der Bearbeitung verarbeitet und nicht gespeichert.

🔒 Keine Anmeldung  |  🚫 Keine Werbung  |  ⚡ Temporär verarbeitet, nicht gespeichert  |  📖 Open Source

⚡ Schnellstart in 3 Schritten

1

Auf USB exportieren

Exportieren Sie die Senderliste über das TV-Menü (Sender > Experteneinstellungen) auf einen USB-Stick (FAT32).

2

Hier hochladen

Ziehen Sie die Datei (.scm, .tll usw.) per Drag & Drop vom USB-Stick in den Bereich oben. Das Format wird automatisch erkannt.

3

Bearbeiten und herunterladen

Kanäle verschieben, löschen oder sortieren. Wenn Sie fertig sind, laden Sie die Datei herunter und importieren Sie sie zurück auf Ihren Fernseher.
