Willkommen beim TV-Sender-Editor! 👋

Schluss mit stundenlangem Herumfummeln an der Fernbedienung Ihres Fernsehers! Exportieren Sie einfach Ihre Senderliste auf einen USB-Stick und laden Sie sie hier hoch. Organisieren Sie Ihre Sender ganz einfach per Drag-and-Drop oder sortieren Sie sie mit dem „Zauberstab“ 🪄 in Sekundenschnelle.

Deine Datei wird auf unserem Server nur vorübergehend verarbeitet, um die Senderliste auszulesen. Sie wird niemals dauerhaft gespeichert.

Lade eine .scm-, .zip-, sdb.xml- oder servicelist.db-Datei hoch

Wähle deine Samsung-, Sony- oder Hisense-Senderlisten-Datei aus

Hinweis (LG-TV-Nutzer): Unser System unterstützt die XML-basierten .tll-Dateien (GlobalClone) der neuen Generation von LG. Ältere binäre .tll-Dateien werden nicht unterstützt; für diese Dateien nutzen Sie bitte die Desktop-Anwendung ChanSort.

⚠️ Haftungsausschluss: Dieses Tool steht in keiner Verbindung zu einem TV-Hersteller. Bitte speichern Sie vor der Bearbeitung eine Sicherungskopie Ihrer ursprünglichen Senderlisten-Datei an einem sicheren Ort. Unser System übernimmt keine Verantwortung für mögliche Datenverluste.
