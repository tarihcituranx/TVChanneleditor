Glossário de satélite e televisão

Pode encontrar abaixo os significados dos termos técnicos e abreviaturas (em inglês e turco) que vê nas definições dos canais de televisão ou na nossa página de detalhes.

SID (Service ID)

Turco: Service ID / Número
do canal Descrição: Um número de identificação único atribuído a cada canal que transmite dentro de uma frequência (pacote). A sua televisão distingue os canais com base neste número SID, e não pelos seus nomes.

TSID (Identificação do Fluxo de Transporte)

Turco: Transport Stream ID
Descrição: Um código único atribuído a cada um dos centenas de pacotes de frequência (portadoras) no mesmo satélite. Funciona em conjunto com o Original Network ID (ONID).

Sistema de Modulação (Modulação)

Tradução: Padrão de Transmissão (DVB-S / DVB-S2)
Descrição: Especifica o formato em que o canal é transmitido a partir do espaço. Enquanto as transmissões mais antigas (de definição padrão) utilizam geralmente o DVB-S, as transmissões de alta definição (HD / 4K) utilizam o padrão DVB-S2, que oferece uma melhor compressão de dados.

Fator de Roll-Off

Turco: Nitidez
do filtro Descrição: Indica o grau de nitidez com que o sinal é filtrado para impedir que se espalhe para frequências adjacentes à medida que se propaga. (São utilizados valores como 0,20, 0,25, 0,35.) Normalmente, este valor é definido automaticamente para os utilizadores.

NID (Identificador de Rede)

Turco: ID
da rede Descrição: Trata-se do identificador da rede de satélite à qual está ligado. Funciona em conjunto com o ONID (ID original da rede). Para os satélites Türksat, este valor é normalmente 1070.

ONID (ID de Rede Original)

Turco: ID
de Rede Original Descrição: Trata-se do código único, registado a nível global, da rede da emissora (por exemplo, Türksat, Astra, Hotbird). Isto permite que o seu dispositivo determine a que rede de satélite está ligado.

PID de vídeo / PID de áudio

Turco: Identificador de Pacotes de Vídeo e Áudio (Identificador de Pacotes)
Descrição: Quando os dados de um canal chegam do espaço, apresentam-se sob a forma de pacotes separados. O PID de Vídeo identifica apenas os pacotes de vídeo, enquanto o PID de Áudio identifica apenas os pacotes de áudio. O televisor extrai estes pacotes e combina-os.

PID PCR (Referência do Relógio do Programa)

Tradução: Referência
do Relógio do Programa Explicação: Trata-se de um código de relógio de referência que garante que os pacotes de áudio e vídeo recebidos do espaço estejam sincronizados segundo a segundo (para que os movimentos labiais e o som ocorram simultaneamente).

FEC (Correção Antecipada de Erros)

Turco: Taxa
de Correção Antecipada de Erros Descrição: A taxa à qual os dados perdidos são matematicamente estimados e corrigidos pelo recetor de satélite em condições meteorológicas adversas ou quando o sinal é fraco. É normalmente expressa como rácios, tais como 3/4 ou 5/6.

Taxa de símbolos

Turco: Taxa
de Transmissão de Dados Explicação: A quantidade de dados digitais (símbolos) transmitidos do satélite para o recetor por segundo. No satélite Türksat, é normalmente de 27 500 (ksps) ou 30 000 (ksps).
