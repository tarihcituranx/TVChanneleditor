Satellite and TV Glossary

You can find the meanings of the technical terms and abbreviations (in English and Turkish) that you see in TV channel settings or on our details page below.

SID (Service ID)

Turkish: Service ID / Channel Number
Description: A unique identification number assigned to each channel broadcasting within a frequency (packet). Your TV distinguishes between channels based on this SID number, not by their names.

TSID (Transport Stream ID)

Turkish: Transport Stream ID
Description: A unique code assigned to each of the hundreds of frequency packets (carriers) on the same satellite. It works in conjunction with the Original Network ID (ONID).

Modulation System (Modulation)

Translation: Broadcast Standard (DVB-S / DVB-S2)
Description: Specifies the format in which the channel is transmitted from space. While older (Standard Definition) broadcasts generally use DVB-S, high-definition (HD / 4K) broadcasts use the DVB-S2 standard, which offers better data compression.

Roll-Off Factor

Turkish: Filter Sharpness
Description: Indicates how sharply the signal is filtered to prevent it from spilling into adjacent frequencies as it propagates. (Values such as 0.20, 0.25, 0.35 are used.) This is generally set automatically for users.

NID (Network ID)

Turkish: Network ID
Description: This is the identifier of the satellite network you are connected to. It works in conjunction with the ONID (Original Network ID). For Türksat satellites, this value is typically 1070.

ONID (Original Network ID)

Turkish: Original Network ID
Description: This is the globally registered, unique code of the broadcaster’s network (e.g., Türksat, Astra, Hotbird). This allows your device to determine which satellite network it is connected to.

Video PID / Audio PID

Turkish: Video and Audio Packet Identifier (Packet Identifier)
Description: When a channel’s data arrives from space, it is in the form of separate packets. The Video PID identifies only the video packets, while the Audio PID identifies only the audio packets. The television extracts these packets and combines them.

PCR PID (Program Clock Reference)

Translation: Program Clock Reference
Explanation: This is a reference clock code that ensures the audio and video packets received from space are synchronized second by second (so that lip movements and sound occur simultaneously).

FEC (Forward Error Correction)

Turkish: Forward Error Correction Rate
Description: The rate at which lost data is mathematically estimated and corrected by the satellite receiver under poor weather conditions or when the signal is weak. It is typically expressed as ratios such as 3/4 or 5/6.

Symbol Rate

Turkish: Data Transmission Rate
Explanation: The amount of digital data (symbols) transmitted from the satellite to the receiver per second. On the Türksat satellite, it is typically 27,500 (ksps) or 30,000 (ksps).
