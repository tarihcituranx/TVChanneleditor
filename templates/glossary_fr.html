Glossaire du satellite et de la télévision

Vous trouverez ci-dessous la signification des termes techniques et des abréviations (en anglais et en turc) qui apparaissent dans les paramètres des chaînes de télévision ou sur notre page de détails.

SID (Service ID)

Turc : Service ID / Numéro
de chaîne Description : Numéro d'identification unique attribué à chaque chaîne diffusant sur une fréquence (paquet). Votre téléviseur distingue les chaînes en fonction de ce numéro SID, et non de leur nom.

TSID (Transport Stream ID)

Turc : Transport Stream ID
Description : Code unique attribué à chacun des centaines de paquets de fréquences (porteuses) sur un même satellite. Il fonctionne en association avec l'identifiant de réseau d'origine (ONID).

Système de modulation (Modulation)

Traduction : Norme de diffusion (DVB-S / DVB-S2)
Description : Spécifie le format dans lequel la chaîne est transmise depuis l'espace. Alors que les diffusions plus anciennes (définition standard) utilisent généralement le DVB-S, les diffusions en haute définition (HD / 4K) utilisent la norme DVB-S2, qui offre une meilleure compression des données.

Facteur de coupure

Turc : Précision
du filtre Description : Indique le degré de précision avec lequel le signal est filtré pour éviter qu’il ne déborde sur les fréquences adjacentes lors de sa propagation. (Des valeurs telles que 0,20, 0,25, 0,35 sont utilisées.) Ce paramètre est généralement défini automatiquement pour les utilisateurs.

NID (identifiant de réseau)

Turc : Identifiant
du réseau Description : il s’agit de l’identifiant du réseau satellite auquel vous êtes connecté. Il fonctionne en conjonction avec l’ONID (identifiant de réseau d’origine). Pour les satellites Türksat, cette valeur est généralement 1070.

ONID (identifiant de réseau d'origine)

Turc : Identifiant
réseau d’origine Description : Il s’agit du code unique, enregistré à l’échelle mondiale, du réseau du diffuseur (par exemple, Türksat, Astra, Hotbird). Cela permet à votre appareil de déterminer à quel réseau satellite il est connecté.

PID vidéo / PID audio

En turc : Identifiant de paquet vidéo et audio (Packet Identifier)
Description : Lorsque les données d’une chaîne arrivent de l’espace, elles se présentent sous la forme de paquets distincts. Le PID vidéo identifie uniquement les paquets vidéo, tandis que le PID audio identifie uniquement les paquets audio. Le téléviseur extrait ces paquets et les combine.

PID PCR (référence d'horloge du programme)

Traduction : Référence
d’horloge du programme Explication : Il s’agit d’un code d’horloge de référence qui garantit que les paquets audio et vidéo reçus de l’espace sont synchronisés seconde par seconde (afin que les mouvements des lèvres et le son se produisent simultanément).

FEC (Correction d’erreurs sans voie de retour)

Turc : Taux
de correction d’erreurs sans voie de retour Description : Taux auquel les données perdues sont mathématiquement estimées et corrigées par le récepteur satellite en cas de mauvaises conditions météorologiques ou lorsque le signal est faible. Il est généralement exprimé sous forme de ratios tels que 3/4 ou 5/6.

Débit symbolique

Turc : Taux
de transmission de données Explication : Quantité de données numériques (symboles) transmises par seconde du satellite au récepteur. Sur le satellite Türksat, il est généralement de 27 500 (ksps) ou 30 000 (ksps).
