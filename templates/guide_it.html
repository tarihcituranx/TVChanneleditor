Guida per l'utente

1 Trasferire l'elenco dei canali su una chiavetta USB
Utilizzando il telecomando della TV, procedere come segue: Menu → Trasmissione → Impostazioni canali → Trasferisci elenco canali. Inserire il PIN (di solito 0000 ) e selezionare l’opzione “Trasferisci su USB ”.

Modelli precedenti (E/F/H): .scm Viene creato un file.
Modelli recenti (J/K/M/Q/R/T - Tizen): .zip viene creato un file.
2 Caricare il file sul sito web
Collega la chiavetta USB al computer. Trascina il file nell’area di caricamento sulla pagina iniziale .scm oppure .zip trascinare il file nell’area di caricamento sulla pagina iniziale oppure fare clic sul pulsante "Seleziona file".
3. Organizza i canali
Riorganizza i canali utilizzando il drag-and-drop. 🪄 Applica modelli predefiniti con la Bacchetta Magica oppure 🛠️ creane uno personalizzato con il Creatore di Modelli. Puoi modificare il 🔒 blocco e i contrassegni dei preferiti su ogni riga di canali.
4. Salva e carica sulla TV
Fai clic sul pulsante “Salva e scarica” . Copia il file scaricato su una chiavetta USB (usa lo stesso nome del file originale!). Caricalo tramite il menu della TV utilizzando “Carica da USB ”.
💡 Suggerimento: la TV riconosce solo i file SCM con lo stesso nome esatto. Quando copi il nuovo file sulla chiavetta USB, sovrascrivi quello vecchio oppure esegui un backup di quest’ultimo .bak con la relativa estensione.
⚠️ Attenzione: il processo di modifica dei canali non modifica le frequenze né i dati PID crittografati dei canali esistenti; aggiorna solo l’ordine e i flag.
1 Trasferire l’elenco dei canali su USB
Sulla TV LG, vai su Impostazioni → Canali → Gestione canali → Copia canali su USB. Sulla chiavetta USB GlobalClone00001.TLL o LG_DTV_*.tll verrà creato un file come questo.
2. Caricare il file .TLL
Carica un file con il .tll . Il sistema riconoscerà automaticamente il formato XML di GlobalClone.
3. Modifica e scarica
Ordina i canali tramite drag-and-drop. Fai clic sul pulsante "Salva e scarica" per scaricare il file TLL aggiornato e trasferirlo su una chiavetta USB. Completa la procedura selezionando "Carica canali da USB" dal menu del televisore.
💡 Sui dispositivi LG webOS 5, a volte potrebbero essere applicate delle restrizioni all’importazione dell’elenco dei canali. Se viene visualizzata una schermata nera, prova a riavviare la TV.
1. Ottenere il file sdb.xml
Su un Sony BRAVIA, segui questi passaggi: Impostazioni → Configurazione canali → Importa elenco canali → Importa su USB. Sulla chiavetta USB sdb.xml o nelle sottocartelle *.xml verranno creati dei file.
2. Carica il file sdb.xml
Vai alla schermata iniziale sdb.xml . Il sistema riconosce automaticamente il file nel formato Sony ed elenca i canali.
3. Modifica e carica sulla TV
Modifica i canali, quindi fai clic su “Salva e scarica” per sdb.xml scaricare il file. Copialo su una chiavetta USB e caricalo sulla TV utilizzando l’opzione “Importa da USB”.
1. Ottenere il file servicelist.db
Sulla TV Hisense, vai su Menu → Canali → Esporta elenco canali per trasferire il file di database su una chiavetta USB. Il nome del file è solitamente servicelist.db (2017+) oppure channel.db (2015–2016).
2. Installa il database
Trascinare il servicelist.db . Il sistema legge il database SQLite ed elenca tutti i canali.
3 Modifica e carica
Dopo aver apportato le modifiche desiderate, fare clic sul pulsante "Salva e scarica" per scaricare il file del database aggiornato. Copiarlo su una chiavetta USB e utilizzare il menu di importazione della TV per importarlo.
⚠️ Le modifiche al nome dei canali sono limitate sui modelli Hisense; su alcuni modelli è possibile applicare solo modifiche relative all’ordinamento e al blocco.
