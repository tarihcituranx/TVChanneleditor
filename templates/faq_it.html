Frequently Asked Questions

General Topics

Currently, Samsung (.scm and .zip), LG (.tll), Sony BRAVIA (sdb.xml), and Hisense (servicelist.db) are fully supported. Panasonic is in beta; Philips, Toshiba, and Grundig will be added soon.
Check the file extension based on your TV brand:
• Samsung (old): .scm
• Samsung (Tizen/new): .zip
• LG: .tll
• Sony BRAVIA: sdb.xml
• Hisense: servicelist.db or channel.db
The editor will automatically detect the brand once you upload the file.
Magic Wand matches channels by name (case-insensitive). If you have "TRT1 HD" in your template, it finds "trt1 hd" in the uploaded file and moves it to the correct position. It does not touch frequency and PID data.
Copy the downloaded file to a USB flash drive (keep the original filename!). Use the Import from USB option from the TV menu.
This site only edits the TV's existing channel list; it cannot add new channels. To see a new channel, you must first do a Network Scan (Auto Tuning) on the TV, then export the new file.
The system compares the channel's saved frequency with the current Turksat frequency database. If the channel was scanned on an old or different frequency, a yellow warning is shown. This is just for your information; the channel will continue to work, but it is recommended to move the channel to its current frequency by doing a new Network Scan on the TV.
Uploaded channel list files are kept on our server only temporarily during processing and are deleted immediately after the process is finished. No channel names, frequencies, or personal data are logged, stored, or shared with third parties. All processing is done on the server side and only the output file is sent to you.

Samsung Smart TV

For Samsung: Follow the steps Menu → Broadcasting → Channel Settings → Transfer Channel List → Export to USB. The TV usually only accepts files with the exact same name, so do not rename the file when editing and restoring.
SCM (Samsung Channel Map) is a special archive file where Samsung TVs store channel order, favorite lists, and frequency data. It contains binary data files such as map-SateD (channel list) and TransponderDataBase.dat (frequency database).
Older Samsung models (E, F, H Series, 2012–2014) use .scm files.
Newer Samsung Tizen models (J, K, M, Q, R, T Series, 2015 and later) use .zip files containing an SQLite database.
This editor automatically detects both formats by inspecting the contents, not just the file extension.

LG Smart TV

TLL (TLL Channel List) is LG's GlobalClone backup format. Insert a USB drive and export from Settings → General → About → Channel Backup Configuration (CLONE). On some models: Menu → Support → Update → Update from USB. The file is usually named xx########.tll.

Sony BRAVIA

For Sony BRAVIA, insert a USB drive and go to Settings → Channel Setup → Channel List Transfer → Export to USB. A file named sdb.xml will be created. For Android TV models, use Settings → Device Preferences → Channel → Channel List Transfer.

Hisense Smart TV

Go to Menu → Channel → Channel List Export. A file named servicelist.db or channel.db will be created. The filename varies by model and firmware, but both SQLite formats are supported.
