Domande frequenti

Argomenti generali

Attualmente sono pienamente supportati Samsung (.scm e .zip), LG (.tll), Sony BRAVIA (sdb.xml) e Hisense (servicelist.db). Panasonic è in versione beta; Philips, Toshiba e Grundig saranno aggiunti a breve.
Controlla l’estensione del file in base alla marca del tuo televisore:
• Samsung (vecchio) : .scm
• Samsung (Tizen/nuovo): .zip
• LG: .tll
• Sony BRAVIA: sdb.xml
• Hisense: servicelist.db oppure channel.db
L'editor rileverà automaticamente la marca una volta caricato il file.
Smart Templates abbina i canali in base al nome (senza distinzione tra maiuscole e minuscole). Se nel modello è presente "TRT1 HD", individua "trt1 hd" nel file caricato e lo sposta nella posizione corretta. Non modifica i dati relativi alla frequenza e al PID.
Copia il file scaricato su una chiavetta USB (mantieni il nome del file originale! ). Utilizza l’opzione “Importa da USB” dal menu della TV.
Questo sito modifica solo l’elenco dei canali esistente sulla TV; non può aggiungere nuovi canali. Per visualizzare un nuovo canale, devi prima eseguire una scansione della rete (sintonizzazione automatica) sulla TV, quindi esportare il nuovo file.
Il sistema confronta la frequenza salvata del canale con l’attuale database delle frequenze di Turksat. Se il canale è stato rilevato su una frequenza precedente o diversa, viene visualizzato un avviso giallo. Si tratta solo di un’informazione; il canale continuerà a funzionare, ma si consiglia di spostarlo sulla sua frequenza attuale effettuando una nuova scansione della rete sul televisore.
I file degli elenchi dei canali caricati vengono conservati sul nostro server solo temporaneamente durante l’elaborazione e vengono eliminati immediatamente al termine del processo. Nessun nome di canale, frequenza o dato personale viene registrato, archiviato o condiviso con terze parti. Tutta l’elaborazione avviene sul lato server e ti viene inviato solo il file di output.

Smart TV Samsung

Per Samsung: segui questi passaggi: Menu → Trasmissione → Impostazioni canali → Trasferisci elenco canali → Esporta su USB. La TV di solito accetta solo file con lo stesso nome esatto, quindi non rinominare il file durante la modifica e il ripristino.
SCM (Samsung Channel Map) è uno speciale file di archivio in cui i televisori Samsung memorizzano l’ordine dei canali, gli elenchi dei preferiti e i dati relativi alle frequenze. Contiene file di dati binari quali map-SateD (elenco dei canali) e TransponderDataBase.dat (database delle frequenze).
I modelli Samsung più vecchi (serie E, F, H, 2012–2014) utilizzano .scm file ZIP.
I modelli Samsung Tizen più recenti (serie J, K, M, Q, R, T, dal 2015 in poi) utilizzano .zip file contenenti un database SQLite.
Questo editor rileva automaticamente entrambi i formati analizzandone il contenuto, non solo l’estensione del file.

Smart TV LG

TLL (TLL Channel List) è il formato di backup GlobalClone di LG. Inserisci una chiavetta USB ed esporta da Impostazioni → Generali → Informazioni → Configurazione backup canali (CLONE) . Su alcuni modelli: Menu → Assistenza → Aggiornamento → Aggiorna da USB . Il file è solitamente denominato xx########.tll.

Sony BRAVIA

Per Sony BRAVIA, inserisci una chiavetta USB e vai su Impostazioni → Configurazione canali → Trasferimento elenco canali → Esporta su USB. Verrà creato un file denominato sdb.xml . Per i modelli Android TV, utilizzare Impostazioni → Preferenze dispositivo → Canali → Trasferimento elenco canali.

Smart TV Hisense

Accedi a Menu → Canali → Esporta elenco canali. Verrà creato un file denominato servicelist.db o channel.db . Il nome del file varia a seconda del modello e del firmware, ma entrambi i formati SQLite sono supportati.
