Perguntas frequentes

Tópicos gerais

Atualmente, a Samsung (.scm e .zip), a LG (.tll), a Sony BRAVIA (sdb.xml) e a Hisense (servicelist.db) são totalmente suportadas. A Panasonic está em fase beta; a Philips, a Toshiba e a Grundig serão adicionadas em breve.
Verifique a extensão do ficheiro consoante a marca da sua televisão:
• Samsung (antiga) : .scm
• Samsung (Tizen/nova): .zip
• LG: .tll
• Sony BRAVIA: sdb.xml
• Hisense: servicelist.db ou channel.db
O editor irá detetar automaticamente a marca assim que carregar o ficheiro.
Os Modelos Inteligentes associam os canais pelo nome (sem distinção entre maiúsculas e minúsculas). Se tiver «TRT1 HD» no seu modelo, o sistema encontra «trt1 hd» no ficheiro carregado e move-o para a posição correta. Não altera os dados de frequência e PID.
Copie o ficheiro descarregado para uma pen USB (mantenha o nome original do ficheiro! ). Utilize a opção «Importar a partir de USB» no menu da televisão.
Este site apenas edita a lista de canais existente na televisão; não pode adicionar novos canais. Para ver um novo canal, deve primeiro efetuar uma «Pesquisa de Rede» (Sintonização Automática) na televisão e, em seguida, exportar o novo ficheiro.
O sistema compara a frequência guardada do canal com a base de dados atual de frequências da Turksat. Se o canal tiver sido detetado numa frequência antiga ou diferente, é apresentado um aviso amarelo. Isto é apenas para sua informação; o canal continuará a funcionar, mas recomenda-se que o transfira para a sua frequência atual, efetuando uma nova «Pesquisa de rede» na televisão.
Os ficheiros da lista de canais carregados são mantidos no nosso servidor apenas temporariamente durante o processamento e são eliminados imediatamente após a conclusão do processo. Nenhum nome de canal, frequência ou dados pessoais são registados, armazenados ou partilhados com terceiros. Todo o processamento é realizado no lado do servidor e apenas o ficheiro de saída lhe é enviado.

Samsung Smart TV

Para a Samsung: Siga os passos Menu → Transmissão → Definições de canais → Transferir lista de canais → Exportar para USB. A televisão normalmente só aceita ficheiros com exatamente o mesmo nome, por isso não renomeie o ficheiro ao editá-lo e restaurá-lo.
SCM (Samsung Channel Map) é um ficheiro de arquivo especial onde as televisões Samsung armazenam a ordem dos canais, listas de favoritos e dados de frequência. Contém ficheiros de dados binários, tais como map-SateD (lista de canais) e TransponderDataBase.dat (base de dados de frequências).
Os modelos mais antigos da Samsung (séries E, F e H, de 2012 a 2014) utilizam .scm ficheiros.
Os modelos mais recentes da Samsung Tizen (Séries J, K, M, Q, R e T, de 2015 em diante) utilizam .zip ficheiros que contêm uma base de dados SQLite.
Este editor deteta automaticamente ambos os formatos ao analisar o conteúdo, e não apenas a extensão do ficheiro.

Smart TV da LG

TLL (TLL Channel List) é o formato de cópia de segurança GlobalClone da LG. Insira uma pen USB e exporte a partir de Definições → Geral → Sobre → Configuração de Cópia de Segurança de Canais (CLONE) . Em alguns modelos: Menu → Suporte → Atualizar → Atualizar a partir de USB . O ficheiro tem normalmente o nome xx########.tll.

Sony BRAVIA

Para a Sony BRAVIA, insira uma pen USB e aceda a Definições → Configuração de canais → Transferência da lista de canais → Exportar para USB. Será criado um ficheiro denominado sdb.xml será criado. Para modelos de Android TV, utilize Definições → Preferências do dispositivo → Canais → Transferência da lista de canais.

Smart TV Hisense

Aceda a Menu → Canal → Exportação da Lista de Canais. Será criado um ficheiro denominado servicelist.db ou channel.db será criado. O nome do ficheiro varia consoante o modelo e o firmware, mas ambos os formatos SQLite são suportados.
