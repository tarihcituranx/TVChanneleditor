Guide d'utilisation

1 Transférer la liste des chaînes vers une clé USB (FAT32)
À l'aide de la télécommande du téléviseur, procédez comme suit : Menu → Diffusion → Paramètres des chaînes → Transférer la liste des chaînes. Saisissez votre code PIN (généralement 0000 ) et sélectionnez l'option « Transférer vers une clé USB ».

Anciens modèles (E/F/H) : .scm Un fichier est créé.
Nouveaux modèles (J/K/M/Q/R/T - Tizen) : .zip un fichier est créé.
2 Téléverser le fichier sur le site web
Branchez la clé USB sur votre ordinateur. Faites glisser le fichier vers la zone de téléchargement sur la page d’accueil .scm ou .zip glissez-déposez le fichier dans la zone de téléchargement de la page d'accueil, ou cliquez sur le bouton « Sélectionner un fichier ».
3. Organiser les chaînes
Réorganisez les chaînes par glisser-déposer. 🪄 Appliquez des modèles prêts à l’emploi avec Smart Templates ou 🛠️ créez les vôtres avec le Template Creator. Vous pouvez modifier les icônes 🔒 de verrouillage et de favoris sur chaque ligne de chaîne.
4. Enregistrer et transférer vers le téléviseur
Cliquez sur le bouton « Enregistrer et télécharger » . Copiez le fichier téléchargé sur une clé USB (utilisez le même nom que le fichier d’origine !). Chargez-le via le menu du téléviseur à l’aide de l ’option « Charger depuis une clé USB ».
💡 Astuce : le téléviseur ne reconnaît que les fichiers SCM portant exactement le même nom. Lorsque vous copiez le nouveau fichier sur la clé USB, remplacez l’ancien ou sauvegardez-le .bak avec son extension.
⚠️ Avertissement : le processus de modification des chaînes ne modifie pas les fréquences ni les données PID cryptées des chaînes existantes ; il met uniquement à jour l’ordre et les indicateurs.
1 Transférer la liste des chaînes sur une clé USB
Sur votre téléviseur LG, accédez à Paramètres → Chaînes → Gestion des chaînes → Copier les chaînes sur une clé USB. Sur la clé USB GlobalClone00001.TLL ou LG_DTV_*.tll un fichier comme celui-ci sera créé.
2. Charger le fichier .TLL
Téléchargez un fichier au format .tll . Le système reconnaîtra automatiquement le format XML GlobalClone.
3. Modifier et télécharger
Triez les chaînes par glisser-déposer. Cliquez sur le bouton « Enregistrer et télécharger » pour télécharger le fichier TLL mis à jour et transférez-le sur une clé USB. Terminez le processus en sélectionnant « Charger les chaînes depuis une clé USB » dans le menu du téléviseur.
💡 Sur les appareils LG webOS 5, des restrictions d’importation de la liste des chaînes peuvent parfois s’appliquer. Si un écran noir s’affiche, essayez de redémarrer le téléviseur.
1. Récupérez le fichier sdb.xml
Sur un téléviseur Sony BRAVIA, procédez comme suit : Paramètres → Configuration des chaînes → Importation de la liste des chaînes → Importer depuis une clé USB. Sur la clé USB sdb.xml ou dans des sous-dossiers *.xml des fichiers seront créés.
2. Chargez le fichier sdb.xml
Accédez à l'écran d'accueil sdb.xml . Le système reconnaît automatiquement le fichier au format Sony et affiche la liste des chaînes.
3. Modifier et télécharger sur le téléviseur
Modifiez la liste des chaînes, puis cliquez sur « Enregistrer et télécharger » pour sdb.xml télécharger le fichier. Copiez-le sur une clé USB et chargez-le sur le téléviseur à l'aide de l'option « Importer depuis une clé USB ».
1. Récupérez le fichier servicelist.db
Sur votre téléviseur Hisense, accédez à Menu → Chaînes → Exporter la liste des chaînes pour transférer le fichier de base de données sur une clé USB. Le nom du fichier est généralement servicelist.db (2017+) ou channel.db (2015–2016).
2. Installez la base de données
Faites glisser le servicelist.db . Le système lit la base de données SQLite et répertorie toutes les chaînes.
3. Modifier et télécharger
Après avoir effectué les modifications souhaitées, cliquez sur le bouton « Enregistrer et télécharger » pour télécharger le fichier de base de données mis à jour. Copiez-le sur une clé USB et utilisez le menu d'importation du téléviseur pour l'importer.
⚠️ Les modifications de nom de chaîne sont limitées sur les modèles Hisense ; sur certains modèles, seuls le tri et le verrouillage peuvent être modifiés.
