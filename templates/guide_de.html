Benutzerhandbuch

1 Übertragen Sie die Senderliste auf einen USB-Stick
Führen Sie mit der Fernbedienung des Fernsehers folgende Schritte aus: Menü → Sendung → Kanaleinstellungen → Senderliste übertragen. Geben Sie Ihre PIN ein (in der Regel 0000 ) und wählen Sie die Option „Auf USB übertragen “.

Ältere Modelle (E/F/H): .scm Es wird eine Datei erstellt.
Neue Modelle (J/K/M/Q/R/T – Tizen): .zip Es wird eine Datei erstellt.
2 Laden Sie die Datei auf die Website hoch
Schließen Sie den USB-Stick an Ihren Computer an. Ziehen Sie die Datei in den Upload-Bereich auf der Startseite .scm oder .zip ziehen Sie die Datei per Drag & Drop in den Upload-Bereich auf der Startseite oder klicken Sie auf die Schaltfläche „Datei auswählen“.
3. Kanäle organisieren
Ordnen Sie die Kanäle per Drag & Drop neu an. 🪄 Wenden Sie vorgefertigte Vorlagen mit dem Zauberstab an oder 🛠️ erstellen Sie eigene mit dem Vorlagen-Generator. Sie können die 🔒 Sperr- und Favoriten-Markierungen in jeder Kanalzeile ändern.
4. Speichern und auf den Fernseher hochladen
Klicken Sie auf die Schaltfläche „Speichern und Herunterladen “. Kopieren Sie die heruntergeladene Datei auf einen USB-Stick (verwenden Sie denselben Namen wie bei der Originaldatei!). Laden Sie sie über das TV-Menü mit „Von USB laden “ auf.
💡 Tipp: Der Fernseher erkennt nur SCM-Dateien mit genau demselben Namen. Wenn du die neue Datei auf den USB-Stick kopierst, überschreibe entweder die alte Datei oder sichere die alte Datei .bak mit ihrer Dateiendung.
⚠️ Warnung: Die Bearbeitung der Senderliste ändert weder die Frequenzen noch die verschlüsselten PID-Daten bestehender Sender; es werden lediglich die Reihenfolge und die Kennzeichnungen aktualisiert.
1 Übertragen Sie die Senderliste auf USB
Gehen Sie auf Ihrem LG-Fernseher zu „Einstellungen“ → „Kanäle“ → „Kanalisverwaltung“ → „Kanäle auf USB kopieren“. Auf dem USB-Stick GlobalClone00001.TLL oder LG_DTV_*.tll wird eine Datei wie diese erstellt.
2. Laden Sie die .TLL-Datei hoch
Laden Sie eine Datei mit der .tll . Das System erkennt das GlobalClone-XML-Format automatisch.
3. Bearbeiten und Herunterladen
Sortieren Sie die Sender per Drag-and-Drop. Klicken Sie auf die Schaltfläche „Speichern und Herunterladen“, um die aktualisierte TLL-Datei herunterzuladen und auf einen USB-Stick zu übertragen. Schließen Sie den Vorgang ab, indem Sie im TV-Menü „Sender von USB laden“ auswählen.
💡 Bei Geräten mit LG webOS 5 gelten manchmal Einschränkungen beim Importieren der Senderliste. Wenn ein schwarzer Bildschirm angezeigt wird, starten Sie den Fernseher neu.
1. Die sdb.xml-Datei bereitstellen
Führen Sie auf einem Sony BRAVIA die folgenden Schritte aus: Einstellungen → Kanaleinrichtung → Kanalliste importieren → Auf USB importieren. Auf dem USB-Stick sdb.xml oder in Unterordnern *.xml werden Dateien erstellt.
2. Laden Sie die sdb.xml-Datei
Gehen Sie zum Startbildschirm sdb.xml . Das System erkennt die Datei im Sony-Format automatisch und listet die Sender auf.
3. Bearbeiten und auf den Fernseher hochladen
Bearbeiten Sie die Sender, klicken Sie anschließend auf „Speichern“ und „Herunterladen“, um sdb.xml die Datei herunterzuladen. Kopieren Sie sie auf einen USB-Stick und laden Sie sie über „Von USB importieren“ auf den Fernseher.
1. Die Datei „servicelist.db“ abrufen
Gehen Sie auf Ihrem Hisense-Fernseher zu „Menü“ → „Kanäle“ → „Kanalliste exportieren“, um die Datenbankdatei auf einen USB-Stick zu übertragen. Der Dateiname lautet in der Regel servicelist.db (2017+) oder channel.db (2015–2016).
2. Installieren Sie die Datenbank
Ziehen Sie die servicelist.db . Das System liest die SQLite-Datenbank aus und listet alle Kanäle auf.
3. Bearbeiten und Hochladen
Nachdem Sie die gewünschten Änderungen vorgenommen haben, klicken Sie auf die Schaltfläche „Speichern und Herunterladen“, um die aktualisierte Datenbankdatei herunterzuladen. Kopieren Sie diese auf einen USB-Stick und importieren Sie sie über das Importmenü des Fernsehers.
⚠️ Bei Hisense-Modellen sind Änderungen der Kanalnamen eingeschränkt; bei einigen Modellen können nur Sortier- und Sperreinstellungen vorgenommen werden.
