## ✨ ما فائدته؟

إنه أداة مفتوحة المصدر تتيح لك تحرير ملف قائمة القنوات الذي ينقله تلفازك إلى وحدة التخزين USB بصريًا في متصفحك باستخدام طريقة **السحب والإفلات**. لا يتطلب التثبيت، ويعمل مباشرةً عبر المتصفح أو واجهة برمجة التطبيقات REST API.

## 👤 من يمكنه استخدامه؟

- من يرغبون في تنظيم قائمة قنوات تلفزيون Samsung من جهاز الكمبيوتر
- من يرغبون في تنظيم ملفات XML `.tll` الخاصة بـ LG GlobalClone
- من يعملون مع قوائم `sdb.xml` الخاصة بـ Sony و`servicelist.db` الخاصة بـ Hisense
- المطورون الذين يرغبون في تغيير قائمة القنوات برمجيًا
- أولئك الذين يرغبون في أتمتة قائمة القنوات باستخدام وكلاء الذكاء الاصطناعي (AI Agent)

## 📺 التنسيقات المدعومة (مصفوفة التوافق)

| التنسيق | القراءة | التحرير | إعادة الإنشاء | ملاحظة |
|--------|:---:|:---:|:---:|-----|
| **Samsung `.scm`** | ✅ | ✅ | ✅ | سلسلة E/F/H (ثنائي) |
| **Samsung Tizen `.zip`** | ✅ | ✅ | ✅ | سلسلة J/K/M/Q/R/T (SQLite) |
| **سوني `sdb.xml`** | ✅ | ✅ | ✅ | سلسلة BRAVIA |
| **هيسنس `servicelist.db`** | ✅ | ✅ | ✅ | طرازات 2017 و2021 |
| **LG XML `.tll`** | ✅ | ✅ | ✅ | GlobalClone XML فقط (لا يدعم التنسيق الثنائي) |
| **Panasonic `svl.*`** | 🔜 | 🔜 | 🔜 | مخطط / قيد التطوير |

> **⚠️ ملاحظة مهمة بشأن التوافق مع LG:** لا يتم دعم ملفات **Binary .tll** من الجيل القديم الخاصة بـ LG. يمكن معالجة ملفات `.tll` القائمة على XML (GlobalClone) من الجيل الجديد فقط. بالنسبة للملفات القديمة، يجب عليك استخدام تطبيق *ChanSort* المكتبي.


## ⚠️ قيود مهمة

يرجى مراعاة القيود التقنية التالية قبل الاستخدام:
- **LG Binary TLL:** لا يتم دعم ملفات `.tll` الثنائية من الجيل القديم.
- **Panasonic SVL:** الدعم قيد التطوير (مخطط له).
- **التحقق من التردد:** نشط فقط لبيانات القمر الصناعي Türksat.
- **حد حجم الملف:** يجب ألا يتجاوز حجم الملفات التي يتم تحميلها **2 ميغابايت**.
- **جلسة مؤقتة:** لا يتم تخزين الملفات بشكل دائم، بل يتم حذفها تلقائيًا عند انتهاء الجلسة.

## 🚀 البدء السريع

1. **انقل من التلفزيون إلى USB:** انقل قائمة القنوات من قائمة التلفزيون (البث > الإعدادات المتقدمة) إلى USB بتنسيق FAT32.
2. **التحميل:** اسحب الملف الموجود على USB وأفلته على الموقع.
3. **التحرير:** قم بالترتيب عن طريق السحب والإفلات، أو احذف الملفات غير الضرورية، أو استخدم 💡 القوالب الذكية.
4. **التنزيل:** قم بتنزيل الملف المعدل مرة أخرى على جهاز الكمبيوتر الخاص بك.
5. **التحميل على التلفزيون:** أعد توصيل وحدة التخزين USB بالتلفزيون واستورد القائمة الجديدة.

## 🛰️ دعم الأقمار الصناعية والترددات

يمكن معالجة قوائم قنوات **DVB-S/S2** التي توفرها المحركات (العلامات التجارية) المدعومة. **ميزة التحقق التلقائي من الترددات (اكتشاف الترددات القديمة/الخاطئة) نشطة حاليًا لبيانات Türksat 4A/5B فقط.** أما الأقمار الصناعية الأخرى (Hotbird، Astra، إلخ)، فهي مدعومة بالكامل للترتيب والتنظيم.

## 🔌 كيف تعمل واجهة برمجة التطبيقات (API) للمطورين (REST)؟

يتوفر مسار بسيط من 3 خطوات لوكلاء الذكاء الاصطناعي والمطورين. لمزيد من التفاصيل، يمكنك الاطلاع على روابط [Swagger UI](https://tvchanneleditor.onrender.com/api/docs) أو [مخطط OpenAPI](https://tvchanneleditor.onrender.com/api/openapi.txt).

**الخطوة 1: التحميل (Upload)**
```http
POST /upload
Content-Type: multipart/form-data
```
*(يُرجع كاستجابة `session_id` وقائمة القنوات بتنسيق JSON)*

**الخطوة 2: الإنشاء (Build)**
```http
POST /build
Content-Type: application/json
{
  "session_id": "uuid-...",
  "channels": [ ... قائمة منظمة ... ]
}
```
*(يُرجع كاستجابة رابط `/download/...` الذي يمكن من خلاله تنزيل الملف)*

**الخطوة 3: التنزيل (Download)**
```http
GET /download/{session_id}/{filename}
```
*(يتم تنزيل الملف الثنائي/المؤرشف المعدل)*

## 🔐 الخصوصية والأمان

- يوجد حد لحجم الملف يبلغ **2 ميغابايت**.
- **لا يتم تخزين الملفات بشكل دائم على الخادم.** تتم معالجة الملفات التي تم تحميلها في مساحة تخزين مؤقتة على الخادم طوال مدة جلسة التحرير، ولا يتم أرشفتها بشكل دائم، ويتم حذفها بالكامل تلقائيًا عند انتهاء مدة الجلسة (حوالي ساعة واحدة).
- لا يتم تسجيل أي حسابات أو عضويات أو بيانات قاعدة البيانات.
- عمليات تحليل XML عبر واجهة برمجة التطبيقات (API) محمية بواسطة `defusedxml` (للحماية من هجمات «Billion Laughs»).

## 🧪 نظام الاختبار (CI)

يتميز المشروع بهندسة اختبار **Round-Trip (ذهابًا وإيابًا)**.
- يتم اختبار أن أكواد المحرك التالفة أو المعدلة لا تفسد الهياكل الأصلية لقاعدة بيانات التلفزيون، وذلك باستخدام ملفات اختبار واقعية (fixtures).
- في كل عملية `push` و`PR`، يتم تشغيل ملف `tests/test_roundtrip.py` تلقائيًا على GitHub Actions.
