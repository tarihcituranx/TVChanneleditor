## ✨ این ابزار چه کاری انجام می‌دهد؟

یک ابزار متن‌باز که به شما امکان می‌دهد فایل لیست کانال‌های منتقل‌شده از تلویزیون شما به یک فلش USB را با استفاده از روش **کشیدن و رها کردن** در مرورگرتان، به صورت بصری ویرایش کنید. این ابزار نیازی به نصب ندارد و مستقیماً از طریق مرورگر یا REST API اجرا می‌شود.

## 📺 فرمت‌های پشتیبانی‌شده (ماتریس سازگاری)

| فرمت | خواندن | ویرایش | بازتولید | یادداشت |
|--------|:---:|:---:|:---:|-----|
| **سامسونگ `.scm`** | ✅ | ✅ | ✅ | سری E/F/H (دودویی) |
| **Samsung Tizen `.zip`** | ✅ | ✅ | ✅ | سری‌های J/K/M/Q/R/T (SQLite) |
| **Sony `sdb.xml`** | ✅ | ✅ | ✅ | سری BRAVIA |
| **Hisense `servicelist.db`** | ✅ | ✅ | ✅ | مدل‌های ۲۰۱۷ و ۲۰۲۱ |
| **LG XML `.tll`** | ✅ | ✅ | ✅ | فقط XML GlobalClone (پشتیبانی از باینری نمی‌شود) |
| **پاناسونیک `svl.*`** | 🔜 | 🔜 | 🔜 | برنامه‌ریزی شده / در حال توسعه |

> **⚠️ نکته مهم در مورد سازگاری ال‌جی:** فایل‌های **Binary .tll** نسل قدیمی‌تر ال‌جی پشتیبانی نمی‌شوند. فقط فایل‌های `.tll` نسل جدیدتر مبتنی بر XML (GlobalClone) قابل پردازش هستند. برای فایل‌های قدیمی‌تر، باید از برنامه دسکتاپ *ChanSort* استفاده کنید.

## 🚀 شروع سریع

۱. **انتقال از تلویزیون به USB:** از منوی تلویزیون (پخش > تنظیمات تخصصی)، لیست کانال‌ها را به یک درایو USB با فرمت FAT32 منتقل کنید.
۲. **بارگذاری:** فایل را از درایو USB به روی وب‌سایت بکشید و رها کنید.
۳. **ویرایش:** با کشیدن و رها کردن مرتب کنید، موارد غیرضروری را حذف کنید یا از قالب‌های هوشمند 💡 استفاده کنید.
۴. **دانلود:** فایل ویرایش‌شده را دوباره روی رایانه خود دانلود کنید.
۵. **نصب روی تلویزیون:** درایو USB را دوباره به تلویزیون وصل کرده و لیست جدید را وارد کنید.

## 🛰️ پشتیبانی از ماهواره و فرکانس

لیست‌های کانال **DVB-S/S2** را می‌توان بدون هیچ مشکلی از نظر فرمت پردازش کرد. **ویژگی تأیید خودکار فرکانس (تشخیص فرکانس‌های قدیمی/نادرست) در حال حاضر فقط برای داده‌های Türksat 4A/5B فعال است.** سایر ماهواره‌ها (Hotbird، Astra و غیره) برای مرتب‌سازی و ویرایش به طور کامل پشتیبانی می‌شوند.

## 🔌 API توسعه‌دهنده (REST) چگونه کار می‌کند؟

یک گردش کار سه‌مرحله‌ای ساده برای نمایندگان هوش مصنوعی و توسعه‌دهندگان وجود دارد. برای جزئیات بیشتر، لطفاً به پیوندهای [رابط کاربری Swagger](https://tvchanneleditor.onrender.com/api/docs) یا [شمای OpenAPI](https://tvchanneleditor.onrender.com/api/openapi.txt) مراجعه کنید.

**مرحله ۱: بارگذاری**
```http
POST /build
Content-Type: application/json
{
  "session_id": "uuid-...",
  "channels": [ ... list sorted ... ]
}
```
*(یک `session_id` و یک لیست JSON از کانال‌ها را در پاسخ برمی‌گرداند)*

**مرحله ۲: ساخت**
```http
POST /build
Content-Type: application/json
{
  "session_id": "uuid-...",
  "channels": [ ... لیست پردازش‌شده ... ]
}
```
*(یک لینک `/download/...` را بازمی‌گرداند که از طریق آن می‌توان فایل را دانلود کرد)*

**مرحله ۳: دانلود**
```http
GET /download/{session_id}/{filename}
```
*(فایل باینری/آرشیو ویرایش‌شده دانلود می‌شود)*

## 🔐 حریم خصوصی و امنیت

- محدودیت حجم فایل **۲ مگابایت** وجود دارد.
- **فایل‌ها به‌طور دائم روی سرور ذخیره نمی‌شوند.** فایل‌های بارگذاری‌شده در طول جلسه ویرایش در یک حافظه موقت نگهداری می‌شوند و هنگامی که جلسه منقضی می‌شود (تقریباً ۱ ساعت)، به‌طور خودکار و کامل حذف می‌شوند.
- هیچ‌گونه حساب کاربری، عضویت یا ثبت لاگ در پایگاه داده وجود ندارد.
- عملیات پردازش XML در API (برای محافظت در برابر حملات Billion Laughs) توسط `defusedxml` ایمن‌سازی شده است.

## 🧪 سیستم تست (CI)

این پروژه از معماری تست **گردشی (Round-Trip)** استفاده می‌کند.
- با استفاده از فایل‌های تست واقعی (fixtures)، تست‌ها اجرا می‌شوند تا اطمینان حاصل شود که کد موتور اصلاح‌شده یا تغییر یافته، ساختارهای اصلی پایگاه داده تلویزیون را خراب نمی‌کند.
- با هر `push` و `PR`، `tests/test_roundtrip.py` به طور خودکار از طریق GitHub Actions اجرا می‌شود.

## 🌍 پشتیبانی از زبان‌ها

رابط کاربری و راهنماهای کاربری در **۱۱ زبان** در دسترس هستند: ترکی، انگلیسی، آلمانی، روسی، اسپانیایی، ایتالیایی، فرانسوی، عربی، فارسی، آذربایجانی و پرتغالی.

## 🏗️ ساختار پروژه

```
├── app.py # سرور Flask، مسیرهای API و i18n
├── scm_core.py # موتور SCM سامسونگ
├── tizen_core.py # موتور SQLite تایزن سامسونگ
├── lg_core.py # موتور XML ال‌جی
├── sony_core.py # موتور XML سونی
├── hisense_core.py     # موتور SQLite هایسنس
├── templates/ # رابط‌های کاربری HTML با Jinja2 (۱۱ زبان)
├── static/ # طرح‌های YAML برای CSS، JS و OpenAPI
└── tests/
    ├── test_roundtrip.py  # تست‌های رفت و برگشتی برای تمام موتورها
    └── fixtures/ # نمونه‌های پایگاه داده تلویزیون واقعی برای تست‌ها
```
