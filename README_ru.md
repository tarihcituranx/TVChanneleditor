## ✨ Для чего это нужно?

Это инструмент с открытым исходным кодом, позволяющий визуально редактировать файл со списком каналов, скопированный с телевизора на USB-накопитель, с помощью метода **«перетаскивания»** в браузере. Не требует установки, работает напрямую в браузере или через REST API.

## 📺 Поддерживаемые форматы (таблица совместимости)

| Формат | Чтение | Редактирование | Восстановление | Примечание |
|--------|:---:|:---:|:---:|-----|
| **Samsung `.scm`** | ✅ | ✅ | ✅ | Серии E/F/H (двоичный формат) |
| **Samsung Tizen `.zip`** | ✅ | ✅ | ✅ | Серии J/K/M/Q/R/T (SQLite) |
| **Sony `sdb.xml`** | ✅ | ✅ | ✅ | Серия BRAVIA |
| **Hisense `servicelist.db`** | ✅ | ✅ | ✅ | Модели 2017 и 2021 годов |
| **LG XML `.tll`** | ✅ | ✅ | ✅ | Только GlobalClone XML (бинарный формат не поддерживается) |
| **Panasonic `svl.*`** | 🔜 | 🔜 | 🔜 | Запланировано / На стадии разработки |

> **⚠️ Важное примечание по совместимости с LG:** Файлы **Binary .tll** старого поколения от LG не поддерживаются. Обрабатываются только файлы `.tll` нового поколения на основе XML (GlobalClone). Для старых файлов необходимо использовать настольное приложение *ChanSort*.

## 🚀 Быстрый старт

1. **Перенесите с телевизора на USB:** через меню телевизора (Трансляция > Расширенные настройки) перенесите список каналов на USB-накопитель, отформатированный в FAT32.
2. **Загрузите:** перетащите файл с USB-накопителя на сайт.
3. **Редактируйте:** сортируйте с помощью перетаскивания, удаляйте ненужные элементы или используйте 💡 «Умные шаблоны».
4. **Скачайте:** скачайте отредактированный файл обратно на компьютер.
5. **Установите на телевизор:** снова подключите USB-накопитель к телевизору и импортируйте новый список.

## 🛰️ Поддержка спутников и частот

Списки каналов в формате **DVB-S/S2** обрабатываются без проблем. **Функция автоматической проверки частот (обнаружение устаревших/неверных частот) в настоящее время активна только для данных Türksat 4A/5B.** Другие спутники (Hotbird, Astra и т. д.) полностью поддерживаются для сортировки и редактирования.

## 🔌 Как работает API для разработчиков (REST)?

Для AI-агентов и разработчиков предусмотрен простой поток из 3 шагов. Более подробную информацию можно найти по ссылкам [Swagger UI](https://tvchanneleditor.onrender.com/api/docs) или [Схема OpenAPI](https://tvchanneleditor.onrender.com/api/openapi.txt).

**Шаг 1: Загрузка (Upload)**
```http
POST /upload
Content-Type: multipart/form-data
```
*(В ответе возвращается `session_id` и список каналов в формате JSON)*

**Шаг 2: Сборка (Build)**
```http
POST /build
Content-Type: application/json
{
  "session_id": "uuid-...",
  "channels": [ ... отредактированный список ... ]
}
```
*(В ответе возвращается ссылка `/download/...`, по которой можно скачать файл)*

**Шаг 3: Загрузка (Download)**
```http
GET /download/{session_id}/{filename}
```
*(Скачивается скомпилированный двоичный файл или архив)*

## 🔐 Конфиденциальность и безопасность

- Существует ограничение на размер файла — **2 МБ**.
- **Файлы не хранятся на сервере на постоянной основе.** Загруженные файлы хранятся во временной памяти на протяжении сеанса редактирования и автоматически полностью удаляются по истечении срока действия сеанса (примерно 1 час).
- Не ведётся никакой регистрации учётных записей, членства или базы данных.
- Операции разбора XML через API (для защиты от атак типа «Billion Laughs») защищены с помощью `defusedxml`.

## 🧪 Система тестирования (CI)

Проект имеет архитектуру тестирования **Round-Trip (туда-обратно)**.
- С помощью реальных тестовых файлов (фикстур) проверяется, что повреждённый или изменённый код движка не нарушает исходную структуру базы данных телепрограмм.
- При каждом `push` и `PR` в GitHub Actions автоматически запускается файл `tests/test_roundtrip.py`.

## 🌍 Языковая поддержка

Интерфейс и руководства по использованию доступны **на 11 языках**: турецком, английском, немецком, русском, испанском, итальянском, французском, арабском, персидском, азербайджанском и португальском.

## 🏗️ Структура проекта

```

```
