## ✨ Для чего это нужно?

Это инструмент с открытым исходным кодом, позволяющий визуально редактировать файл со списком каналов, скопированный вашим телевизором на USB-накопитель, с помощью метода **«перетаскивания»** в браузере. Не требует установки, работает напрямую в браузере или через REST API.

## 👤 Кто может использовать?

- Те, кто хочет редактировать список каналов телевизоров Samsung с компьютера
- Те, кто хочет редактировать файлы LG GlobalClone XML `.tll`
- Те, кто работает со списками Sony `sdb.xml` и Hisense `servicelist.db`
- Разработчики, желающие программно изменять список каналов
- Те, кто хочет автоматизировать управление списком каналов с помощью агентов искусственного интеллекта (AI Agent)

## 📺 Поддерживаемые форматы (матрица совместимости)

| Формат | Чтение | Редактирование | Восстановление | Примечание |
|--------|:---:|:---:|:---:|-----|
| **Samsung `.scm`** | ✅ | ✅ | ✅ | Серии E/F/H (двоичный формат) |
| **Samsung Tizen `.zip`** | ✅ | ✅ | ✅ | Серии J/K/M/Q/R/T (SQLite) |
| **Sony `sdb.xml`** | ✅ | ✅ | ✅ | Серия BRAVIA |
| **Hisense `servicelist.db`** | ✅ | ✅ | ✅ | Модели 2017 и 2021 годов |
| **LG XML `.tll`** | ✅ | ✅ | ✅ | Только GlobalClone XML (бинарный формат не поддерживается) |
| **Panasonic `svl.*`** | 🔜 | 🔜 | 🔜 | Запланировано / На стадии разработки |

> **⚠️ Важное примечание по совместимости с LG:** Файлы **Binary .tll** старого поколения от LG не поддерживаются. Обрабатываются только файлы `.tll` нового поколения на основе XML (GlobalClone). Для работы со старыми файлами необходимо использовать настольное приложение *ChanSort*.


## ⚠️ Важные ограничения

Перед использованием, пожалуйста, учтите следующие технические ограничения:
- **LG Binary TLL:** Двоичные файлы `.tll` старого поколения не поддерживаются.
- **Panasonic SVL:** Поддержка находится в стадии разработки (в планах).
- **Проверка частоты:** Активна только для данных спутника Türksat.
- **Ограничение размера файла:** размер загружаемых файлов не должен превышать **2 МБ**.
- **Временная сессия:** файлы не сохраняются на постоянной основе и автоматически удаляются по окончании сессии.

## 🚀 Быстрый старт

1. **Перенос с телевизора на USB:** В меню телевизора (Эфир > Расширенные настройки) перенесите список каналов на USB-накопитель, отформатированный в FAT32.
2. **Загрузите:** перетащите файл с USB-накопителя на сайт.
3. **Отредактируйте:** отсортируйте файлы с помощью перетаскивания, удалите ненужные или воспользуйтесь 💡 «Умными шаблонами».
4. **Скачайте:** Скачайте отредактированный файл обратно на компьютер.
5. **Загрузите на телевизор:** Снова подключите USB-накопитель к телевизору и импортируйте новый список.

## 🛰️ Поддержка спутников и частот

Можно обрабатывать списки каналов **DVB-S/S2**, предоставляемые поддерживаемыми движками (брендами). **Функция автоматической проверки частот (обнаружение устаревших/неверных частот) в настоящее время активна только для данных Türksat 4A/5B.** Другие спутники (Hotbird, Astra и т. д.) полностью поддерживаются для сортировки и редактирования.

## 🔌 Как работает API для разработчиков (REST)?

Для AI-агентов и разработчиков предусмотрен простой 3-этапный процесс. Более подробную информацию можно найти по ссылкам [Swagger UI](https://tvchanneleditor.onrender.com/api/docs) или [Схема OpenAPI](https://tvchanneleditor.onrender.com/api/openapi.txt).

**Шаг 1: Загрузка (Upload)**
```http
POST /upload
Content-Type: multipart/form-data
```
*(В ответе возвращается `session_id` и список каналов в формате JSON)*

**Шаг 2: Сборка (Build)**
```http
POST /build
Content-Type: application/json
{
  "session_id": "uuid-...",
  "channels": [ ... отредактированный список ... ]
}
```
*(В ответе возвращается ссылка `/download/...`, по которой можно скачать файл)*

**Шаг 3: Загрузка (Download)**
```http
GET /download/{session_id}/{filename}
```
*(Скачивается обработанный двоичный файл или архив)*

## 🔐 Конфиденциальность и безопасность

- Существует ограничение на размер файла — **2 МБ**.
- **Файлы не хранятся на сервере постоянно.** Загруженные файлы обрабатываются во временном хранилище сервера на протяжении сеанса редактирования, не архивируются на постоянной основе и автоматически полностью удаляются по истечении срока действия сеанса (примерно 1 час).
- Отсутствует любая регистрация учетных записей, членства или ведение журналов базы данных.
- Операции разбора XML через API (для защиты от атак типа «Billion Laughs») защищены с помощью `defusedxml`.

## 🧪 Система тестирования (CI)

Проект имеет архитектуру тестирования **Round-Trip (туда-обратно)**.
- С помощью реальных тестовых файлов (fixtures) проверяется, что поврежденный или измененный код движка не нарушает исходную структуру базы данных телепрограмм.
- При каждом `push` и `PR` в GitHub Actions автоматически запускается скрипт `tests/test_roundtrip.py`.

## 🌍 Языковая поддержка

Интерфейс и руководства по использованию доступны **на 11 языках**: турецком, английском, немецком, русском, испанском, итальянском, французском, арабском, персидском, азербайджанском и португальском.
